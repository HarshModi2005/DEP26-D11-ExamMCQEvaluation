# Student List Data

This directory contains mock and real dataset files (CSVs and Excel files) representing student rosters, grades, and quiz evaluation lists. 

## 📁 Usage

These files are typically used for:
- Testing the dataset upload functionality in the frontend.
- Validating the local SQLite data ingestion scripts on the backend.
- Providing baseline mock data during local development and testing to ensure the evaluation engine handles large rosters effectively.
